Expression analysis

Upload bulk RNA-seq (genes × samples). Each sample is classified as epithelial, hybrid, or mesenchymal using a multi-GMT consensus epithelial/mesenchymal program panel (MSigDB 2023.2 — Hallmark, Foroutan, Hollern, Sarrio, Kohn, Jechlinger, Reactome, WikiPathways).

Input data

Drop CSV here or click to browse · genes as rows, samples as columns
Prefer log₂(TPM+1). Raw counts use all genes in the file as the library size (CPM ≠ TPM; no gene-length correction).

Format requirements

  • First column: HGNC gene symbols
  • Remaining columns: samples
  • Consensus E/M genes from all MSigDB EMT GMTs (support ≥ 2)
  • States: 2D high/low rule (epithelial / hybrid / mesenchymal)
